# CaliforniaUnemploymentAnalysis
Analysis of unemployment trends across California regions using U.S. government labor force data.

Project Overview: 
This project analyzes labor force and unemployment trends across California regions using publicly available U.S. government data. The goal of the project is to identify long term unemployment patterns, any regional discrepancies, and how different areas respond to economic changes over time. 

Dataset: 
Source: U.S. government labor force and unemployment data (Data.gov)
Time Period: 1990 through 2024. 
Geographic Area: California (state,counties, and metropolitan areas)

The data includes: 
- Labor Force size
- Employment counts
- Unemployment counts
- Unemployment rates
- Area type (state, county, metropolitan area)

Objectives: 
The objective in this project is to analyze how unemployment rates in California have changed over time, to compare unemployment trends across counties and metropolitan areas, identify regions with higher or lower unemployment, and to highlight major economic periods and their regional impacts. 

Tools and Technologies: 
- Python
- Visual Studio Code
- GitHub
